# TaskFlow

A Task Management website with Laravel(PHP), VUE.js, SQLite.

## Architecture

![Functions Architecture](https://github.com/Jodieadver/TaskFlow/blob/master/img/Architecture.png)

## Features

- User Register, Login, Logout
- Create, edit, delete Project
- Create, edit, delete, assign Task
- Member invitation through email
